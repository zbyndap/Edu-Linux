1.3 Konfigurace síťového rozhraní

Serverové služby · 6 vyučovacích hodin
Výzva Zkoumání Řešení Reflexe Zdroje

Výzva

Big Idea

Stabilní a správně nakonfigurovaná síťová připojení jsou základem bezpečné a spolehlivé serverové infrastruktury. Bez nich server nemůže komunikovat se zbytkem sítě a poskytovat své služby.

Essential Question

Jak nakonfigurovat a diagnostikovat síťové rozhraní tak, aby server bezpečně a spolehlivě komunikoval v síti?

Challenge

Na serveru vytvořeném v Kapitole 1.2 (IP adresa 192.168.1.10, doména vyuka.cz) potřebujete:

  1. Ověřit a zdokumentovat aktuální konfiguraci síťového rozhraní (ip addr, ethtool, nmtui)
  2. Konfiguraci zálohovat a vytvořit zálohu konfigurace v souboru /etc/network/interfaces
  3. Diagnostikovat síť pomocí nástrojů (ping, traceroute, netstat, ss, dig)
  4. Zdokumentovat výsledky diagnostiky a vytvořit tabulku pro správce sítě

Master Challenge: Tato kapitola zajišťuje, že Škola X má stabilní a diagnostikovatelné síťové připojení — nezbytné pro všechny následující služby (DNS, DHCP, web, atd.).

Ověřené zdroje

Relevance: Podrobný průvodce síťovou konfigurací v Debianu — statické IP, DHCP, DNS, brána, маршрутизáce.

Klíčové body:

  • Tradiční metoda: /etc/network/interfaces
  • Moderní metoda: netplan, nmcli
  • Souborová struktura síťové konfigurace
  • Restart síťových služeb bez výpadku

Zdroj: Debian Handbook — Chapter 8: System Administration (https://debian-handbook.info/browse/stable/system-administration.html)

Relevance: Moderní i zastaralé nástroje pro diagnostiku síťe — oba jsou důležité, protože starší systémy ještě starý nástroje používají.

Praktické příkazy:

# Zobrazit IP adresy a rozhraní ip addr show ip link show # DNS resolver cat /etc/resolv.conf dig vyuka.cz nslookup server.vyuka.cz # Routing tabulka ip route show route -n # Aktivní porty a spojení ss -tlnp netstat -tulpn # Otestovat síť ping 192.168.1.1 traceroute 8.8.8.8 mtr 8.8.8.8

Zdroj: Linux man-pages project (https://man7.org/)

Relevance: Detailní informace o fyzickém rozhraní — rychlost, duplex mód, čítače chyb.

Příkazy:

# Zobrazit vlastnosti rozhraní ethtool eth0 ethtool -S eth0 # Statistika ethtool -d eth0 # Diagnostika # Nastavit duplex ethtool -s eth0 speed 1000 duplex full autoneg on # Zobrazit all rozhraní s IP ip link ip addr # Interaktivní konfigurace (NetworkManager) nmtui nmcli conn show

Zdroj: Linux Kernel Documentation

Relevance: Statický config soubor pro síťová rozhraní — nejčastější a nejspolehlivější metoda v serverovém prostředí.

Příklad konfigurace pro server (Debian/Ubuntu):

# /etc/network/interfaces source /etc/network/interfaces.d/* auto lo iface lo inet loopback auto eth0 iface eth0 inet static address 192.168.1.10/24 gateway 192.168.1.1 dns-nameservers 192.168.1.1 8.8.8.8 # IPv6 (pokud je dostupné) iface eth0 inet6 static address 2001:db8::10/64 gateway 2001:db8::1

Aplikace změn:

# Bez restartu (pokud jste na konzoli mimo SSH): ifdown eth0 && ifup eth0 # Nebo restart síťové služby: systemctl restart networking # Ověření: ip addr show eth0 ip route show

Zdroj: man interfaces (5), Debian Wiki

Relevance: Jak nastavit DNS resolvery a lokální hostname resolution — kritické pro komunikaci po jménech místo IP adres.

DNS nastavení:

# /etc/resolv.conf — obvykle generován systemd-resolved # V novějších Debianu se konfiguruje přes netplan nebo /etc/network/interfaces # Ruční přidání DNS (pokud je potřeba): nameserver 192.168.1.1 # Lokální DNS server nameserver 8.8.8.8 # Google DNS (fallback) # Lokální hostname resolution: # /etc/hosts 127.0.0.1 localhost ::1 localhost 192.168.1.10 server.vyuka.cz server # Ověření: getent hosts server.vyuka.cz dig server.vyuka.cz @192.168.1.1 nslookup server.vyuka.cz

Zdroj: man resolv.conf (5), man hosts (5)

Doporučení pro praxi: Při konfiguraci síťě na serveru (speciálně přes SSH) vždy:

  • ✓ Vytvořte zálohu aktuální konfigurace
  • ✓ Zapište si příkazem, jak vrátit zpět (ifdown/ifup)
  • ✓ Pracujte na konzoli (ne SSH), pokud to možné
  • ✓ Po každé změně otestujte základní konektivitu (ping, dns lookup)
  • ✗ Nikdy neaplikujte velké změny bez možnosti vrácení se
