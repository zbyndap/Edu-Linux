Vrstvy grafického rozhraní Linuxu

Než začnete instalovat, projděte si, jak jsou jednotlivé vrstvy grafického rozhraní poskládané nad sebou a jak spolu komunikují — každá vrstva se dá vyměnit nezávisle na ostatních.

Badatelské otázky

    Od hardwaru k pracovní ploše — čtyři vrstvy nad sebou

    Grafické rozhraní Linuxu není jeden program, ale sada nezávislých vrstev. Dnešní hodina se týká tří prostředních vrstev — X server, display manager a window manager/desktop environment.

    Proč se to takhle odděluje: každá vrstva řeší jinou věc a dá se vyměnit bez zásahu do ostatních.

    • X server — jediná vrstva, která přímo mluví s grafickou kartou, klávesnicí a myší.
    • Display manager — stará se jen o přihlašovací obrazovku a spuštění zvolené session.
    • Window manager / desktop environment — určuje, jak vypadají a chovají se okna po přihlášení.

    Architektura X Window Systému — kdo je server a kdo klient

    V X Window Systému je vztah server–klient obrácený, než by čekal. X server běží přímo na počítači uživatele a obsluhuje hardware. Aplikace (terminál, editor, prohlížeč souborů) jsou jeho klienti — posílají mu požadavky na vykreslení oken a odebírají od něj události z klávesnice a myši. Protokol je navíc síťově transparentní: klient může běžet i na jiném počítači v síti a stále kreslit do X serveru na vaší obrazovce.

    IceWM vs. XFCE4 — dva přístupy k pracovní ploše

    icewm je minimalistický window manager — jeho autoři cílí na rychlost, jednoduchost a to, aby uživateli „nepřekážel v cestě". Nabízí jen okna, lištu úkolů a přepínání pomocí klávesnice. XFCE4 je naproti tomu plnohodnotný desktop environment — má vlastní správce souborů, panel, nastavení vzhledu i správce session — a přitom zůstává výrazně odlehčenější než GNOME nebo KDE Plasma.
